# Task 4 - Logistic Regression

## Objective
Build a binary classification model using Logistic Regression.

## Dataset
Breast Cancer Wisconsin Dataset

## Steps Performed
1. Loaded dataset
2. Split train and test data
3. Standardized features
4. Trained Logistic Regression model
5. Evaluated using:
   - Confusion Matrix
   - Precision
   - Recall
   - ROC-AUC
6. Plotted ROC Curve

## Tools Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
